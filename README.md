# 📦 Stock Control – Sistema de Controle de Estoque

Sistema de controle de estoque desenvolvido em **C# utilizando Programação Orientada a Objetos**.  
O projeto foi criado com o objetivo de praticar conceitos fundamentais da linguagem e estruturas de dados como **Dictionary**, além de reforçar boas práticas de organização de código.

---

# 🚀 Funcionalidades

O sistema permite:

- 📌 Cadastrar novos produtos
- 💰 Alterar o preço de produtos
- ➕ Adicionar unidades ao estoque
- ➖ Remover unidades do estoque
- 📋 Listar todos os produtos cadastrados
- 🔎 Validação de entradas do usuário

---

# 🧠 Conceitos aplicados

Durante o desenvolvimento deste projeto foram utilizados:

- **C#**
- **Programação Orientada a Objetos (POO)**
- **Classes e Métodos**
- **Encapsulamento**
- **Dictionary (estrutura chave-valor)**
- **Validação de entrada com TryParse**
- **Separação de responsabilidades em funções**
- **Estrutura de menus em aplicações console**

---

# 🛠 Tecnologias utilizadas

- **C#**
- **.NET**
- **Console Application**

# 🎯 Objetivo do projeto

Este projeto foi desenvolvido como prática de aprendizado para consolidar conceitos importantes de desenvolvimento backend com **C#**, especialmente:

- modelagem de classes
- manipulação de objetos
- controle de fluxo
- estruturação de aplicações simples
